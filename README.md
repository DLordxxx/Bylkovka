# Bylkovka
Автоматизированная система учета (АСУ) академических задолженностей на платформе «1С:Предприятие».
Проект выполнен для Московского университета им. С.Ю. Витте (2024–2025).

## Моя роль
- Руководитель проекта / Бизнес-аналитик: полный цикл от сбора требований до внедрения.
- Архитектор: проектирование структуры базы данных и логики учета в 1С.
- Разработчик: реализация системы, настройка конфигурации под нетиповые задачи.
- Документирование: техническое задание (ТЗ), сопроводительная документация, регламенты работы.

## Результат
- Получен патент на разработку, подтверждающий уникальность архитектуры и экспертизу в 1С.
- Система автоматизирует учет академических задолженностей.

## Статус
Проект завершен, не поддерживается.
